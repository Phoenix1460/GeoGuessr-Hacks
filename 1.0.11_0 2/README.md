# GeoGuessr Boost Chrome Extension

Manifest V3-версия. Расширение работает в боковой панели Chrome, читает
координаты текущего раунда на поддерживаемых игровых сайтах и может
автоматически поставить пин на карте. API-ключи в расширении не хранятся.

## Установка для теста

1. Откройте `chrome://extensions`.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked**.
4. Выберите эту папку `extension`.
5. Откройте GeoGuessr, OpenGuessr, WorldGuessr, FreeGuessr или Geotastic и нажмите иконку **GeoGuessr Boost** на панели Chrome.

Основной сценарий:

- нажмите `G` — расширение проверит текущий раунд и покажет найденное место;
- в настройках боковой панели можно назначить любую другую одиночную клавишу;
- хоткей игнорируется, когда курсор находится в поле ввода.

Бесплатный режим даёт 5 стартовых guesses, затем 1 guess в день. В бесплатном
режиме все функции доступны и для бесплатных guesses. Range и Auto Guess по умолчанию выключены; платный доступ снимает только лимит guesses.
Скриншоты не отправляются на AI-анализ.

Язык интерфейса и подсказок выбирается в настройках. По умолчанию используется
английский. Доступны English, Français, Deutsch, Русский, Polski, Español,
Português, Nederlands и Svenska.

После изменения файлов нажмите кнопку **Reload** на карточке расширения в
`chrome://extensions`.

## Ограничения тестовой версии

- Поддерживаются GeoGuessr, OpenGuessr, WorldGuessr, FreeGuessr и Geotastic.
- Если координаты раунда не найдены, расширение показывает ошибку и не делает
  запасной запрос по скриншоту.
- Для читаемого названия места используется reverse geocoding.
