GeoGuessr Boost

Installed

Find the round. Place the pin.

GeoGuessr Boost works on supported geography-game rounds. Keep the game tab active, press one key, and use the side panel to review the found place.

Quick start
  1. 1
    Open a supported round

    Start a supported geography game and keep that tab active.

  2. 2
    Press G

    G is the default analysis key. You can change it in Settings.

  3. 3
    Use the result

    Auto Place is enabled by default. Auto Guess, Smart Zoom, and Range unlock with Pro.

Default key G
