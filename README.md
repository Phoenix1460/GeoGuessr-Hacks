
# GeoGuessr-Hacks
This Chrome Extension automatically places a pin exactly where the correct location is on the geoguessr map.

# how to install:
download the folder named GeoGuessrHelper in this repo
Go to chrome extensions page

# How to use
In any geoguessr game, after installing this extension, press the P key and the extension will automatically place the pin on the exact location on the map that you are. It will not click submit answer so you must do that yourself.
